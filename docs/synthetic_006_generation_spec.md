# synthetic_006 追加生成指示書 — 90°〜120° 帯の補強

- 版: v1.0(2026-09-03)
- 根拠データ: [data/yawpose/augmentation_plan_s006.json](../data/yawpose/augmentation_plan_s006.json)
  (`labels_fixed.jsonl` 41,423 件の 10° ビン集計、目標 1,200 件/ビン)
- 納品先: `data/synthetic_006/`
- **共通要件は [synthetic_004_generation_spec.md](synthetic_004_generation_spec.md) v1.1 に全面準拠**
  (yaw 規約 §2、姿勢・構図 §4、多様性 §5、納品形式 §6、自動 QA §7)。
  本書は差分のみ規定する。

## 1. 目的

教師 v5(κ + EMA、s005 統合データで学習)の per_bin 検証で、s005 が補強した
両隣(80-90°: 11.4° / 120-150° 帯)に対し **90-120° 帯だけが相対劣化**
(v3 比 12.7° → 14.5°)した。未強化の谷(90-100: 1,233 / 100-110: 990 /
110-120: 792 件)が相対的な最弱帯となったため、1,200 件/ビンへ引き上げる。

## 2. 生成量(ビン別割当)

不足数合計 **618**、QA 落ち 15% を見込んだ生成指示数 **712**。
ビン内の yaw は整数度で一様分布させる(90-100 は既に 1,233 件で対象外)。

| yaw ビン | 現状 | 不足数 | 生成指示数 |
|---:|---:|---:|---:|
| 100–110 | 990 | 210 | 242 |
| 110–120 | 792 | 408 | 470 |
| **計** | 1,782 | **618** | **712** |

## 3. 見え方アンカー(s004 spec §4 の該当帯)

- 100–110: 完全〜浅い後方プロファイル(左)。**左耳と鼻先の輪郭**が見える。
  目は片目がぎりぎり見えるか見えない(`visible_side`: profile_left)
- 110–120: 後方 1/4(左)。**左耳と頬・顎の輪郭のみ**、目・鼻・口は見えない
  (`visible_side`: left_ear)

## 4. QA・人手レビュー

- 自動 QA は s004 spec §7 準拠。**本帯は |yaw| 90〜120° で、90〜95° 相当の行は
  sixd + ランドマークの符号検証が部分適用可能**。95° 超は Face(16) 高スコア検出を
  不合格候補とする逆チェック
- 人手レビューは 10% 抽出(intent_match 不合格率 15% 超で全数)

## 5. 取り込み(受領後の作業メモ)

1. `build_yawpose_dataset.py` の s004/s005 汎用ブロックに `synthetic_006` を追加
   (リスト 1 行の変更。`label_source = "intent_s006"`)
2. `fix_labels.py` の s004/s005 分岐にも `synthetic_006` を追加 → 再実行 →
   train/val 再分割 → **教師再ラベルの再適用**(最新教師の best を使用)
3. `plot_yaw_distribution.py` / `plan_augmentation.py --ranges 90-120
   --target 1200 --out augmentation_plan_s006.json` で達成確認
4. 教師の短期更新 → 蒸留の再実行
