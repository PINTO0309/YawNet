# synthetic_005 追加生成指示書 — 難領域重点補強(yaw 120°〜180° / 210°〜270°)

- 版: v1.0(2026-09-03)
- 根拠データ: [data/yawpose/augmentation_plan_s005.json](../data/yawpose/augmentation_plan_s005.json)
  (`labels_fixed.jsonl` 35,713 件の 10° ビン集計、目標 1,200 件/ビン)
- 納品先: `data/synthetic_005/`
- **共通要件は [synthetic_004_generation_spec.md](synthetic_004_generation_spec.md) v1.1 に全面準拠**
  (yaw 規約 §2、姿勢・構図 §4、多様性 §5、納品形式 §6、自動 QA §7)。
  本書は差分のみ規定する。

## 1. 目的

教師(DINOv3 ViT-L)・学生(YawNet)とも、後方 3/4 ビュー帯
(120°〜180° / 210°〜270°)の検証誤差が他帯(10〜14°)より高い(16〜28°)。
量は他帯と同等(平均 787 件/ビン)であり、原因は
(a) 視覚手がかりの少ない本質的難領域であること、
(b) s001 由来の残存ラベルノイズ(特に 120-150°)である。
対策として本帯を **1,200 件/ビン(他帯の約 1.5 倍)** へ増強し、
学習信号の強化と、検証分割へのクリーンラベル希釈の両方を狙う。

## 3. 見え方アンカー(s004 spec §4 の該当帯を必ず使用)

全ビンが後方系のため、プロンプトの visible_side 言語指定を特に厳密に:

- 120–140 / 220–250: 後方 1/4。**耳と頬・顎の輪郭のみ**、目・鼻・口は見えない
  (`visible_side`: 120 側 = left_ear、230 側 = right_ear)
- 140–175 / 210–220: ほぼ後頭部。**耳が部分的に見える程度**、顔要素なし
- 175–180: 純粋な後頭部(耳もほぼ不可視)
- 250–270: 完全〜浅い後方プロファイル。**右耳と鼻先の輪郭**が見える

髪型・頭部アクセサリの多様性を s004 同様に厚くする(後頭部の見た目を支配するため)。

## 4. QA・人手レビュー

- 自動 QA は s004 spec §7 に準拠。本データは全ビンが |yaw|>95° 相当の後方帯
  ではない点に注意: **250°〜270°(= −110°〜−90°)は sixd + ランドマークの
  符号検証が部分的に適用可能**なので、|signed| ≤ 95° の行は自動検証を実施する
- 人手レビューは**全ビン 10% 抽出**(自動符号検証が効かない帯が大半のため。
  intent_match 不合格率 15% 超で当該ビン全数レビュー)

## 5. 取り込み(受領後の作業メモ)

1. `build_yawpose_dataset.py` に s005 ソースを追加
   (`yaw_deg = yaw_yawpose % 360`、規約反転不要、`label_source = "intent_s005"`)
2. `fix_labels.py` に s005 分岐(s004 と同処理)を追加して再実行 → train/val 再分割
   ※ 教師再ラベル済み行の `yaw_deg` を維持するため、再分割後に
   `relabel_rear_teacher.py` の再適用が必要(教師 v3 best を使用)
3. `plot_yaw_distribution.py` / `plan_augmentation.py --ranges 120-180,210-270
   --target 1200 --out augmentation_plan_s005.json` で達成確認
4. 教師 v4 を短期再学習(wsd、12 epochs 目安)→ 蒸留の再実行
